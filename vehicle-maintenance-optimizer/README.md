# Vehicle Maintenance Scheduler

Knapsack optimization problem solver for vehicle maintenance scheduling.

## Problem Statement
Given vehicles with maintenance requirements and depots with limited capacity, optimize the schedule to maximize the number of vehicles serviced.

## Algorithm
Uses knapsack dynamic programming approach to find optimal solution.
